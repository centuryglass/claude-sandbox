# Asset provenance

Everything the renderer's own code produces (procedural meshes, the nebula
environment map) is covered by this repo's `LICENSE` (Unlicense) same as
the code. A few files here are not this project's own work and carry their
own status:

- `external/bunny.obj` - the Stanford bunny, the well-known 3D-scan test
  mesh from Stanford University's Computer Graphics Laboratory, used
  throughout computer graphics as a standard stress-test model. Long
  freely redistributed for exactly this kind of use; the exact URL it was
  fetched from wasn't preserved. Used here purely as a triangle-count/
  real-mesh stress test for the OBJ loader and BVH (see `scenes/bunny.ron`).

- `textures/earth.jpg` - NASA's Blue Marble composite, equirectangular-
  projected. NASA imagery is U.S. government work and public domain;
  fetched via three.js's example-asset mirror on GitHub (itself
  MIT-licensed, though the underlying photo's own status is what actually
  matters and is public domain independent of that). Used as an image-
  texture and environment-lighting demo (`scenes/earth.ron`,
  `scenes/earth_environment.ron`).

- `textures/amethyst_reference.png` - the user's own personal photograph
  from a 2013 college project, provided directly for this project as the
  visual reference for the kaleidoscope-fold bug `hit-chain-drift`
  reproduces (see the top-level README's "The real bug" section and
  `reference/`). Not covered by the Unlicense - it's someone's own photo,
  included here for direct comparison/provenance, not as a redistributable
  asset.

- `textures/nebula.png` - fully procedural, generated by
  `examples/gen_starfield.rs` from this renderer's own noise code. No
  external source at all; regenerate it any time with
  `cargo run --release --example gen_starfield`.

An equirectangular "abandoned room" photo was evaluated as an environment
map candidate during development and explicitly rejected - its licensing
was less clearly established than the assets above, so it was never
committed to this repo. The procedural nebula exists specifically to avoid
that problem.
